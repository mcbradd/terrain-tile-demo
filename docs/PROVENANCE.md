# Provenance

## Who made what

- Code: written by AI coding agents, directed by Bradd McBrearty from a written spec.
- Look values: set by Bradd McBrearty.
- Entity tokens: three placeholder tokens generated by `blender/scripts/make_entities.py`. They are not hand-modeled.
- Elevation data: U.S. Geological Survey, 3D Elevation Program, 1/3 arc-second DEM. Source URLs, retrieval time, and SHA-256 are in `data/source/`.

## How correctness is established

- Rules: every rule has an ID, a severity, a measured value, and a limit. `uv run tilepipe validate` writes the results.
- Fixtures: every rule has a test asset or input built to break it.
- Tests: `uv run pytest` covers the code. Determinism is checked by building twice and comparing `outputs.sha256`.

Static validation only. No headset performance measured.
